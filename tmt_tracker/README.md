# TMT Print Tracker

Track the 3D-printed parts of Toddler Mobility Trainer (TMT) builds from your Bambu Lab printers: every part, which
plate prints it, what's printing now, and how far along each TMT is. Each printer gets a print queue, optional phone
alerts with a Plate is clear button, a details pop-up with its camera, per-printer print times, and a build planner.

Upload your TMT design files on the app's page; your printers are found automatically. See the Documentation tab.
